GitHub 적용 방법
1. index.html을 GitHub dkuevelab/dkuevelab.github.io 저장소 최상위 폴더에 업로드하여 같은 이름의 기존 파일 교체.
2. Commit changes. 기존 favicon.svg는 유지 가능.
3. GitHub Actions에서 Pages 배포 완료 후 https://dkuevelab.github.io 확인.
